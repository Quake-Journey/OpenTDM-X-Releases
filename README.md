# OpenTDM-X releases

Finished releases of **OpenTDM-X**, the Quake II duel bot server module, for
Windows (and Ubuntu where provided).

- Server packages: download the archive of a release and follow its README.
- Q2PRO-X integration packages (`*_windows-x86_64.otxpkg.zip` with the
  `*.otxpkg.json` descriptor) are installed and updated by Q2PRO-X itself
  (Settings → OpenTDM-X → Updates).

This repository carries release files only. Every asset is listed with its
SHA-256 digest by GitHub.
